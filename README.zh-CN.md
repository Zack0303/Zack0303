# 你好，我是 Zack 👋

我在做帮助人们开展研究、整理信息的实用 AI 工具。重点是：**容易开始、来源清楚、能够长期维护**。

[English / 返回主页介绍](README.md)

## 🎓 Research Navigator：研究计划助手
面向硕士、博士学生，帮助缩小题目范围、规划研究方法、审阅草稿，并区分学校要求和一般建议。

**不需要工科背景或安装 Codex。**打开网页使用包，将全文复制进 AI 对话，再用熟悉的语言说需求。不同平台的联网和附件能力有所不同。

[开始使用 →](https://github.com/Zack0303/research-navigator/blob/main/README.zh-CN.md) · [查看公开审阅示例](https://github.com/Zack0303/research-navigator/blob/main/examples/public-mres-case.md)

实验项目，采用 MIT 许可证；尚未完成真人易用性及全面语言验证，不保证学校合规或申请结果。

## 📰 AI News Monitor：AI 信息简报
从 RSS 和 GitHub 收集信息，筛选排序，输出中英简报。包含 AI 分析、失败回退和静态页面生成。

[查看项目与使用说明 →](https://github.com/Zack0303/AI-News-Monitor/blob/master/README.zh-CN.md)

实验项目，运行需要本地配置；当前在线运行状态尚未核验。
